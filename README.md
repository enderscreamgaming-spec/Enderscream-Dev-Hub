## Installation

**- 1st method :**
1. Download or copy the raw URL of `Enderscream-Dev-Hub.unistore`. **( https://raw.githubusercontent.com/enderscreamgaming-spec/Enderscream-Dev-Hub/refs/heads/main/Enderscream%20Dev%20Hub.unistore )
2. Open **Universal Updater** on your Nintendo 3DS.
3. Go to **Settings** → **Select UniStore**.
4. Choose **Add UniStore**.
5. Enter the URL (or scan the QR code, if available).
6. Restart or refresh Universal Updater.

The UniStore **"Enderscream Game Hub"** should now appear in the list.

**- 2nd method :** 

You can scan the **Qr code** in the release, or click here : https://github.com/enderscreamgaming-spec/Enderscream-Dev-Hub/releases/tag/qrcode

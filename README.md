## Installation

### Method 1: Using the Raw URL

1. Copy the Raw URL of `Enderscream-Dev-Hub.unistore`:

-  https://raw.githubusercontent.com/enderscreamgaming-spec/Enderscream-Dev-Hub/refs/heads/main/Enderscream%20Dev%20Hub.unistore`

2. Open **Universal Updater** on your Nintendo 3DS.

3. Go to **Settings → Select UniStore**.

4. Choose **Add UniStore**.

5. Paste the URL.

6. Restart or refresh Universal Updater.

The **Enderscream Dev Hub** UniStore should now appear in the list.

### Method 2: Using the QR Code

You can scan the QR code available in the Releases section, or open it here:
